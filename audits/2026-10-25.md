## Newly flagged
1. **Factory rulesets have no required checks, while auto-merge is allowed.** On .github and gh-factory, `allow_auto_merge: true` with a PR rule of 0 approvals and no required checks means an auto-merge request merges as soon as the PR opens. Set `required_checks` in each repo's `factory.yml` (CodeQL / `Analyze (actions)` for .github; CI for gh-factory).
2. **SHA pins on .github #2 diverge from the factory baseline.** The next `gh factory apply` that includes .github will overwrite them back to tags, because the files carry the `factory-managed` marker.
3. **Org-default PR template asks every touchlineHQ repo for a CHANGELOG**, but only .github would have one. That will create noise on [private reference redacted] PRs (Issue Shipper and PR Reviewer will see an unmet checkbox).
4. **gh-factory isn't released or pinned.** Anyone installing it gets main HEAD.
5. **touchlineHQ preview environments have grown to 11** unprotected `github-pages-*` entries.
6. **Dependabot majors will auto-merge at the next weekly run** (likely Mon 26 Oct), with no human review.
